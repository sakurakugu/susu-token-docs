# 快速开始

## 1. 准备 API Key

登录 SusuToken 后，在控制台创建 API Key。

## 2. 配置 Base URL

客户端中使用以下 API 地址：

```text
https://susutoken.com
```

## 3. 配置客户端

推荐使用 [CC Switch](/clients/cc-switch) 作为统一入口，支持多种客户端的热切换。
根据使用的客户端选择对应文档：

- [CC Switch](/clients/cc-switch)
- [Claude Code](/clients/claude-code)
- [Codex](/clients/codex)

## 4. 测试请求

配置完成后，先发送一个简单请求确认 API Key 和模型配置可用。
比如 `ping`，`hi`

如果用 CC Switch，点击右边的`测试模型`图标即可测试

> 如果测试失败，有可能是使用的测试模型没有修改默认值，需要发送简单请求进行测试
